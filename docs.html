FAQ

Is Hyaecord a fork of Equicord or Vencord?

No. Hyaecord is an original client with its own shell, GUI, and internals. What it shares with Equicord/Vencord is the plugin API surface: a compatibility layer lets most existing plugins run unmodified. Plugins that reach into Equicord/Vencord-specific internals or DOM structure may need porting.

Will I get banned for using Hyaecord?

Client modifications are against Discord's Terms of Service, so there is inherent risk. In practice Discord has historically not banned users solely for using client mods, but if losing your account would be a serious problem, you should avoid client mods entirely — Hyaecord included.

What platforms are supported?

Linux is the primary v1 target; Windows is planned as a secondary target. macOS is not planned.

Does Hyaecord collect my data?

No telemetry by default. Features that transmit anything (like cloud settings sync) are opt-in and explained in plain language before you enable them. This website also sets no cookies and runs no analytics — see the privacy policy.

Can I fork Hyaecord?

Yes, always — the code is GPL-3.0. You must rebrand your fork (different name, logo, and app ID) before distributing it publicly, per the trademark policy. Rebranded forks need no permission at all.

How do I report a security issue?

Use GitHub private security advisories — see security.txt.
